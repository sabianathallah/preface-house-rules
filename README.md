# PREFACE Handbook 📋

Modern company handbook website dengan white minimalist design dan PREFACE branding.

![PREFACE Logo](assets/images/logo-preface.jpeg)

## 🎨 Design Features

- ✨ **White Dominant Theme** - Clean & professional
- 🎨 **PREFACE Red Accent** (#E31E24) - Brand identity
- 🔤 **Inter Font** - Modern typography
- 🎯 **Lucide Icons** - Premium icon library
- 📱 **Responsive** - Mobile-friendly design
- ⚡ **Fast Loading** - 52KB gzipped bundle

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
# → http://localhost:3000

# Build for production
npm run build
```

## 📦 Tech Stack

- **React 18.2.0** - UI framework
- **Vite 5.4.21** - Build tool
- **Lucide React** - Icon library
- **327 packages** - Total dependencies
